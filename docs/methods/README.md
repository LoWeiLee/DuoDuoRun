# 方法文件索引（docs/methods/）

> 階段 A 產出（見 `docs/roadmap-v2.md §6`）。一個「可報告的統計方法」一份文件，共八節固定模板。
> **本索引隨階段 A 逐批補齊，目前為進行中狀態。**

## 這批文件是什麼

每份文件回答同一組問題：這個方法在回答什麼問題、什麼時候不該用、公式是什麼、
本工具在有慣例分歧的地方採了哪一個、假設前提怎麼檢核、**哪些部分還沒被驗證**、
報表上每個數字對應哪條公式、紅隊查過哪幾項。

★ 第 6 節「尚未驗證的部分」是這批文件的重點。多多快跑的 82 組基準中有 30 組屬 tier B
（沒有可執行的第三方數值對照，只靠權威文獻與機制同源撐住）——把這件事講清楚，
比宣稱「已完整驗證」誠實，也才對得起審稿人。
