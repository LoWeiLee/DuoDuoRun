## 1. 這個方法在回答什麼問題

一般的迴歸問一個「平均而言」的問題：X 每多一單位，Y 平均多多少。
必要條件分析（NCA）問的是另一種問題：**沒有足夠的 X，Y 就上不去嗎？**

這兩件事在邏輯上並不互通。一個因素可以在迴歸上完全不顯著，卻是不可或缺的門檻；
也可以有很大的平均效果，卻不構成任何門檻。NCA 的判準不看資料的中心，而看**散佈圖的左上角**：
如果「高 Y、低 X」那一塊區域是空的，就代表資料裡沒有任何一個案例能在 X 不足時達到高 Y——
這就是「X 是 Y 的必要條件」的資料痕跡。

CE-FDH 是把「空的那一塊」畫出來的兩種方式之一，也是本工具的主力。
它的作法最直接：**沿著資料的外緣走一條階梯**，

$$\text{ceiling}(x)=\max\{\,y_i : x_i \le x\,\}$$

也就是「X 不超過 $x$ 的那些案例，最高的 Y 是多少」。這條階梯以上、矩形以內的面積，
就是沒有任何案例落入的空白區（ceiling zone）；把它除以整個矩形（scope）就得到效果量 $d$。

$d$ 可以直接用白話讀：**$d = 0.24$ 代表「這個必要條件擋掉了 24% 的可能空間」。**

★ CE-FDH 名字裡的 free disposal hull 來自生產效率文獻：它假設「若 $(x,y)$ 可達，
則任何 $x'\ge x$、$y'\le y$ 也可達」——即多給投入不會變差、少要產出不會變難。
這個假設換到 NCA 的語境就是：ceiling 必須**非遞減**。

## 2. 什麼時候該用、什麼時候不該用

**該用**

- 理論說的是「門檻」「前提」「不可或缺」而不是「越多越好」（如：一定程度的高階主管支持是數位轉型的前提）
- 迴歸做完發現某變項不顯著，但實務上大家都說它必要——這兩件事可以同時為真
- Y 的高分組值得單獨解釋，而不只是平均

**不該用**

- **樣本很小**：ceiling 由**極端值**決定，$n$ 小時整條線可能靠一兩個點撐著。本工具在 $n<5$ 時直接擋（`need-n>=5`，`nca.js:218`）；但 $n=10$ 與 $n=200$ 的穩定度差距極大，工具**不會另外警告**（見第 6 節）
- **X 或 Y 沒有變異**：scope 為 0，$d$ 無定義。工具擋在 `no-variation`（`nca.js:221`）
- **有離群值而未處理**：一個 Y 特別高、X 特別低的離群點會把整條 ceiling 往左上拉，$d$ 隨之縮小甚至歸零。★ **本工具不做離群值篩檢**
- **Y 是二分或極少水準**：階梯只有兩三階，$d$ 的解析度極低

**常見誤用**

1. ★ **把 $d$ 當成解釋力。** $d$ 不是 $R^2$。$d=0.24$ 不是「解釋了 24% 的變異」，而是「散佈圖左上角有 24% 是空的」
2. ★ **把必要條件讀成充分條件。** NCA 說的是「X 不夠，Y 就到不了」，**不是**「X 夠了，Y 就會高」。2026-07-29 起這句限制已寫進 APA 敘述句（見 R43）
3. **拿觀察資料的 NCA 直接下因果結論。** Dul (2016) 本人在原文強調：NCA 找到的是資料中的必要性痕跡，因果解釋要由理論與研究設計承擔
4. **只報 $d$ 不報 $p$，或只報 $p$ 不報 $d$。** 本工具兩者都要通過才判「是必要條件」——這是本工具的複合口徑，見 `nca-permutation.md` §3.3
5. **拿不同資料集的 $d$ 互相比較。** scope 用的是**實證** min/max，換一批資料就換一個分母

## 3. 公式與定義

### 3.1 符號表

| 符號 | 意義 |
|---|---|
| $x_i,\ y_i$ | 第 $i$ 個案例的條件變數與結果變數，$i=1,\dots,n$ |
| $x_{\min},x_{\max},y_{\min},y_{\max}$ | 兩變數的**實證**極值 |
| $S$ | scope，$(x_{\max}-x_{\min})(y_{\max}-y_{\min})$ |
| $(\tilde x_j,\tilde y_j)$ | 第 $j$ 個 peer（階梯轉角點），$j=1,\dots,J$ |
| $C$ | ceiling zone，階梯上方、矩形以內的面積 |
| $d$ | 效果量，$C/S$ |

### 3.2 scope

$$S=(x_{\max}-x_{\min})\,(y_{\max}-y_{\min})$$

★ **慣例分歧：scope 的邊界取實證極值，不是理論極值。**
R `NCA` 套件另有 `scope.theoretical` 選項可指定量表的理論上下界（如李克特 1–7）。
本工具**只實作實證版**，理由是理論界線在多數資料上不可得，而混用兩種 scope 會讓 $d$ 不可比。
⇒ 後果：以本工具算出的 $d$ 與以理論 scope 算出的 $d$ **不能互相比較**。實作見 `nca.js:85–96`。

### 3.3 CE-FDH 的 peers 與階梯

peer 是「跑動最大值被刷新」的點。依 $x$ 遞增掃描（同一 $x$ 取最大 $y$），每當該點的 $y$
超過目前為止的最大值，就記下一個 peer（`nca.js:63–84`）。

$$\text{ceiling}(x)=\max\{\,y_i:x_i\le x\,\}=\tilde y_j \quad\text{for}\quad \tilde x_j\le x<\tilde x_{j+1}$$

★ **並列（ties）慣例**：同一個 $x$ 上有多個案例時取**最大**的 $y$；且刷新條件是**嚴格**大於
（`m > run`，`nca.js:78`），因此與前一個 peer 等高的點**不會**再記一次。
⇒ 這決定了 peer 的**數量**（本基準 $J=8$），而 peer 數是報表上的一個欄位。

### 3.4 ceiling zone 與效果量

階梯上方的空白區以逐段矩形加總（`nca.js:97–105`）：

$$C=\sum_{j=1}^{J}\bigl(y_{\max}-\tilde y_j\bigr)\bigl(\tilde x_{j+1}-\tilde x_j\bigr),\qquad \tilde x_{J+1}:=x_{\max}$$

$$d=\frac{C}{S}$$

$d\in[0,1]$：$d=0$ 表示左上角完全沒有空出來（沒有必要條件的痕跡），$d\to1$ 表示幾乎整個空間都被擋掉。

### 3.5 效果量基準與準確度

Dul (2016) 的基準（`nca.js:27–33`）：

| $d$ | 判讀 |
|---|---|
| $0<d<0.1$ | 小 |
| $0.1\le d<0.3$ | 中 |
| $0.3\le d<0.5$ | 大 |
| $d\ge0.5$ | 非常大 |

**準確度（accuracy）**＝落在 ceiling 線上或其下的觀察值比例。
CE-FDH 是包絡線，依定義**沒有任何點在它之上**，故 accuracy **恆為 1**（`nca.js:236`，硬編為 `accuracy: 1`）。
⇒ 報表上這一欄對 CE-FDH 而言不帶資訊，它存在的意義是與 CR-FDH 並列對照（見 `nca-cr-fdh.md` §3.4）。

## 4. 假設前提與本工具的檢核方式

★ **NCA 完全不在 `assumptionChecker` 的涵蓋範圍內**（`assumptionChecker.js:283–289` 只列 t 檢定、
單因子 ANOVA、相關與三種迴歸）。本方法的所有前置檢核都寫在引擎內，且僅有下列三項：

| 前提 | 工具怎麼檢核 | 違反時 |
|---|---|---|
| 兩變數皆為數值且成對可用 | `runNCACompute` 逐列 listwise 剔除（`compute.js:26–37`） | 剔除筆數自 2026-07-29 起顯示於 scope 行與 APA 句（R37-b） |
| $n\ge5$ | `nca.js:218` | 回 `need-n>=5`，中英訊息自 2026-07-29 補齊（R37-a） |
| $x$ 與 $y$ 都要有變異 | `nca.js:221` | 回 `no-variation` |

**沒有檢核、但方法確實要求的**（誠實列出）：

1. **無離群值**。ceiling 完全由極端點決定，這是 NCA 最脆弱的地方，工具零防禦
2. **測量方向一致**。反向計分題未事先處理時，「空白區」會出現在右下角而不是左上角，$d$ 會接近 0 而工具不會提醒
3. **樣本足以支撐極端值**。$n=5$ 就放行，但此時 ceiling 可能只由 2 個點構成
4. **變數為連續或至少序位**。工具只要求數值，離散水準少時階梯粗糙而無警告

### R43（L2）APA 敘述句對必要性的宣稱過強

**發現**　顯著版 APA 句直述「{x} 是 {y} 的必要條件」，句中沒有任何限制。
「必要非充分」這句話只出現在 **teaching mode 才顯示**的 `interp.sentence`——
而 APA 句正是使用者按「一鍵複製」貼進論文的那一段。Dul (2016) 原文對此限制著墨甚多。

**處置（Kevin 2026-07-29 核定）**　`apa.sentence` 句尾中英各補一個 `{caveat}` 子句，
內容為「必要不蘊含充分」＋「觀察資料的因果解釋須由理論與研究設計支持」。
未達顯著的 `sentenceNs` **不掛** caveat（沒有做出宣稱就不必收回）。
`Narrative.jsx:11–35`、i18n 中英各一鍵；＋2 條行為測試（含「`sentenceNs` 不得含 `{caveat}`」的防修過頭鎖）。
