# 預測導向分段 PLS-POS（Prediction-oriented segmentation）

> 方法代號 `pls_pos`｜基準組 `reference.json → pls_pos`（39 個統計量）＋ `pls_pos_inputs`（固定起始分割，tier I）｜溯源 tier **B** / verified
> 最後更新：2026-07-29（階段 A / A3c）

---

## 1. 這個方法在回答什麼問題

一組路徑係數是**全樣本的平均**。如果樣本其實由結構關係不同的次群體組成，這個平均可能誰都不代表。

最極端的例子就在本工具的模擬資料裡：兩段的真值分別是 $\beta=+0.80$ 與 $-0.80$，
**全樣本估出來是 $+0.318$、$R^2=0.101$**——一個誰也不像的數字。
分成兩段後變成 $+0.889$ 與 $-0.871$，整體 $R^2$ 跳到 **0.780**。

PLS-POS 問的是：**能不能把樣本切成 $K$ 段，讓每一段的內生構念被解釋得更好？**
它用**硬指派**（每個人恰好屬於一段）＋**爬山法**（逐案試搬、只接受讓目標變好的搬移）來找這個切法。

★ **與 FIMIX 的分工**（兩者處理同一個問題，機制完全不同）：

| | FIMIX-PLS | PLS-POS |
|---|---|---|
| 指派 | 軟（後驗機率） | **硬**（屬於某一段） |
| 目標 | 混合模型的對數概似 | **各段各內生構念的 $R^2$ 之和** |
| 演算法 | EM | 逐案重新指派的爬山法 |
| 分布假設 | 常態 | **無** |
| 能否選段數 | 可（8 個資訊準則） | ★ **不可**（見 §2） |

⇒ 兩法找到相似的段時，分段結果比較可信。這是本工具把兩者並列的理由。

## 2. 什麼時候該用、什麼時候不該用

**該用**

- 懷疑樣本有**未觀察的異質性**（不是用性別、部門這種已知變數就能切開的那種）
- 全域模型的 $R^2$ 低得不合理，或路徑係數與理論預期相反
- 想與 FIMIX 互相印證

**不該用**

- ★ ★ **用來決定「該分幾段」。** POS 的目標函數**必然**隨 $K$ 上升（沒有懲罰項）。
  實測本工具的模擬資料：$K=2,3,4,5$ 的目標值為 **1.576 / 2.588 / 3.592 / 4.608**，
  單調遞增且沒有停下來的跡象。用 POS 選 $K$ 只會得到「越多越好」這個荒謬結論。
  段數要靠 FIMIX 的資訊準則、理論、或段別的可解釋性決定。工具**每次都會印這條警告**（`pls.js:4872`）
- **樣本小**：段別越小，段內的 OLS 越不穩。本工具的段別下限預設只有 $\max(3,\ 5\%n)$——
  這是數值穩定性的底線，**不是統計上足夠的樣本數**（見 §4 與第 6 節第 4 點）
- **異質性只存在於測量模型**（不同群體對題目的理解不同）：本實作偵測不到（見第 5 節的範圍限制）
- 含調節項或高階構念的模型：**直接擋**（`rejectW4`，`pls.js:4664–4665`）

**常見誤用**

1. ★ **把分段結果當成「發現了兩種人」。** POS 找到的段是**統計上的**分割，
   要能用可觀察變數事後刻畫（年齡、產業、使用年資……）才有實務意義。
   刻畫不出來的段無法據以行動，也無法在新樣本上重現
2. ★ **拿報表上的 SSE 去比較不同的 $K$。** 報表印的是預測誤差 SSE，**優化的卻是 $\Sigma R^2$**——
   兩者不等價。實測同一筆資料：$K=3$ 的 sseTotal 為 58.70、$K=4$ 反而是 60.22（**變差**），
   而目標值從 2.588 升到 3.592（變好）。**兩個數字給相反的訊息**（見第 8 節 R34-b）
3. **對分段後的係數做組間顯著性檢定。** 段是**用資料找出來的**，不是事先分好的組；
   直接套 MGA 的 $t$ 檢定會嚴重高估顯著性（選擇性推論問題）。本工具不提供這個功能
4. **只跑一次就相信結果。** 爬山法只保證局部最優。預設 10 個隨機起點取最佳，
   但**沒有報告不同起點之間的一致性**
5. **忽略段別大小。** 一個 $n=3$ 的段可以有 $R^2=0.97$，那是過度配適而非發現

## 3. 公式與定義

### 3.1 符號表

| 符號 | 意義 |
|---|---|
| $K$ | 段數（$\ge2$；$K=1$ 即全域模型） |
| $S_k$ | 第 $k$ 段的個案集合 |
| $y_j$ | 內生構念 $j$ 的**全樣本 PLS 標準化分數** |
| $\mathbf{x}_j$ | 構念 $j$ 的結構前置分數向量 |
| $\text{SSE}_{kj}$ | 第 $k$ 段、方程 $j$ 的殘差平方和 |
| $m$ | 段別大小下限（`minSize`） |

★ **關鍵前提：LV 分數取自全樣本 PLS 權重，分段過程中不重估測量模型。**
所以本方法只在**結構模型層**分段。這是本實作對原文的簡化，見第 5 節。

### 3.2 段內迴歸（無截距）

每個內生構念 $j$ 在每一段內跑**無截距**的 OLS：

$$\hat{\boldsymbol\beta}_{kj}=\mathbf{A}_{kj}^{-1}\mathbf{b}_{kj},\qquad
\mathbf{A}_{kj}=\sum_{i\in S_k}\mathbf{x}_{ij}\mathbf{x}_{ij}',\quad
\mathbf{b}_{kj}=\sum_{i\in S_k}\mathbf{x}_{ij}y_{ij}$$

$$\text{SSE}_{kj}=\max\Big(\sum_{i\in S_k}y_{ij}^2-\hat{\boldsymbol\beta}_{kj}'\mathbf{b}_{kj},\ 0\Big),
\qquad R^2_{kj}=1-\frac{\text{SSE}_{kj}}{\sum_{i\in S_k}y_{ij}^2}$$

→ `pls.js:4627–4644`（`posSolve`；奇異時回 $\hat{\boldsymbol\beta}=\mathbf{0}$、$\text{SSE}=\Sigma y^2$）

★ ★ **$R^2$ 的分母是未置中的 $\sum y^2$，不是 $\sum(y-\bar y_k)^2$。**
因為迴歸無截距，這是無截距迴歸的標準慣例。全樣本分數的平均為 0，但**段內平均不為 0**，
所以段別 $R^2$ 與「先取段內平均再算」的版本**不同**。$\sum y^2\le10^{-12}$ 時 $R^2$ 記 0。

### 3.3 目標函數

$$\boxed{\ \text{Obj}=\sum_{k=1}^{K}\sum_{j\in\text{endo}} R^2_{kj}\ }\qquad\textbf{愈大愈好}$$

→ `pls.js:4739–4743`（`r2SumOf`）

★ **這不等價於「最小化各段 SSE 之和」。** 分母 $\sum_{i\in S_k}y^2$ 隨段別組成改變，
兩個目標會收斂到**不同的分割**。Session Q2 的溯源審計正是抓到這一點：
原實作用 $\Sigma\text{SSE}$，原文寫的是 $\Sigma R^2$，改口徑後段別還原率由 0.837 升到 **0.857**
（見第 6 節）。

★ 目標值的量綱：$K$ 段 × 內生構念數 個 $R^2$ 相加，所以**上界是 $K\times|\text{endo}|$**。
不同 $K$ 之間**不可比較**——這正是它不能用來選段數的數學原因。

### 3.4 爬山法

→ `pls.js:4747–4793`（`climb`）

**充分統計量增量更新**：每段每方程只保留 $(\mathbf{A},\mathbf{b},\sum y^2,n)$。
搬移一個個案是 $O(k^2)$ 的加減，不必重跑整段 OLS。→ `pls.js:4720–4730`（`addCase`）

**一輪（pass）的流程**（個案依索引序、目標段依段索引序）：

1. 若移出後來源段會低於下限 $m$ ⇒ **跳過**（`pls.js:4761`）
2. 把個案 $i$ 從所屬段 $s$ 移出，記錄 $s$ 移出前後的 $\Sigma R^2$
3. 對每個 $t\ne s$：試放入、記錄 $t$ 放入前後的 $\Sigma R^2$、再取出
4. 增益 $\;g_t=(R^2_{s,\text{out}}+R^2_{t,\text{in+}})-(R^2_{s,\text{in}}+R^2_{t,\text{in}})$（`pls.js:4774`）
5. 取增益最大且 $>10^{-12}$ 者搬移；**嚴格大於 ⇒ 同分取段索引較小者**（`pls.js:4775`）
6. 都沒有改善 ⇒ 還原到 $s$

一輪掃完沒有任何搬移即停止；上限 `maxPasses`（預設 100，用盡時**警告**，`pls.js:4864–4866`）。

★ **只檢查來源段的下限、不檢查目標段。** 目標段只會變大，所以不會違反下限——
但這也表示**下限只擋得住「段被搬空」，擋不住「一開始就分得很不平衡」**。

★ **單調性自檢**：每輪結束後比對目標值，下降超過 $10^{-6}$ 就推警告
「這在數學上不應發生，請回報此案例」（`pls.js:4787`、`4827–4829`）。

### 3.5 多起始分割與 label switching

- **注入起始分割**（`initAssignment`）：只跑這一個起點，供逐值交叉驗證。
  長度、值域、各段下限三項都檢查（`pls.js:4796–4805`）
- **否則**：`starts` 個隨機起點（預設 10，固定種子 $=\text{seed}+7919K$），
  每個起點先「修補」到滿足下限，取**目標值最大**者（`pls.js:4808–4828`）
- **label switching**：段別依**大小遞減**重新編號（`pls.js:4836–4838`），輸出因此是決定性的

★ 隨機起點的修補邏輯是「從最大的段搬一個過來」，可能在極端情況下修補失敗（`break`），
此時該起點的分割仍會被評估。**未測**。

### 3.6 全域對照

以單一段（全部個案）跑同一套統計量，得 `global.sse`、`global.objective`、`global.r2`。
報表用它與分段後對比。→ `pls.js:4830–4833`、`4843–4855`

$$R^2_{\text{overall}}=1-\frac{\sum_k\sum_j \text{SSE}_{kj}}{\sum_j\sum_i y_{ij}^2}$$

→ `pls.js:4880–4881`

★ $R^2_{\text{overall}}$ 與目標函數 $\Sigma R^2$ **是兩個不同的量**：前者是「總誤差佔總變異的比例」（可比），
後者是「各段 $R^2$ 相加」（隨 $K$ 膨脹，不可比）。報表印的是前者。

## 4. 假設前提與本工具的檢核方式

| 前提 | 本工具怎麼檢核 | 違反時的行為 | 位置 |
|---|---|---|---|
| 不含調節／高階構念 | `rejectW4` | **硬擋** | `pls.js:4664–4665` |
| 至少一條結構路徑 | 檢查 `paths` | **硬擋** `pos-no-structural-path` | `pls.js:4674–4679` |
| $K$ 為 $\ge2$ 的整數 | 型別與範圍 | **硬擋** `pos-bad-segments`，訊息說明「$K=1$ 就是全域模型」 | `pls.js:4681–4684` |
| $n\ge m\times K$ | 計數 | **硬擋** `too-few-cases`，訊息含 $m$、$K$、實際 $n$ | `pls.js:4703–4710` |
| 注入起始分割合法 | 長度／值域／各段下限 | **硬擋** `pos-bad-init`（兩種訊息） | `pls.js:4796–4805` |
| 段內迴歸非奇異 | 高斯消去 pivot $<10^{-12}$ | **不擋**：$\hat\beta=0$、$\text{SSE}=\Sigma y^2$（該段該方程 $R^2=0$），**無警告** | `pls.js:4633` |
| 爬山法收斂 | 輪數計數 | **警告**「可能不是局部最優」 | `pls.js:4864–4866` |
| 目標函數單調 | 每輪比對 | **警告**「數學上不應發生，請回報」 | `pls.js:4787`、`4827–4829` |
| ★ 段數的選擇 | — | **每次都警告**「不能用來選段數」 | `pls.js:4872` |
| ★ 實作範圍 | — | **每次都警告**「結構模型層簡化版」 | `pls.js:4873` |
| **缺失值** | 一律 casewise | **靜默剔除**，`nDropped` 有回傳但**不顯示、無警告** | `pls.js:4898` |
| **微小段** | 段內樣本 < max(10, 5×前置數) | ★ **2026-07-29 起警告**，指名段別與人數（R34-c） | `pls.js:4867–4871` |

★ **本方法對誤差沒有分布假設**——這是它相對 FIMIX 的優勢，也代表**它不提供任何推論**：
沒有 SE、沒有 $p$、沒有 CI。段別係數是點估計，工具**刻意不對它們做檢定**（見 §2 誤用 3）。
