# 二次效果（Quadratic / nonlinear effect）

> 方法代號 `pls_quadratic`｜基準組 `reference.json → pls_quadratic`（7 欄）｜溯源 tier **B** / verified
> 最後更新：2026-07-26（階段 A / A2）

---

## 1. 這個方法在回答什麼問題

線性路徑假設「X 每增加一個單位，Y 的變化量都一樣」。二次效果放寬這個假設，問：
**X 對 Y 的影響會不會隨 X 自己的水準而變？**

典型情境：報酬遞減（X 低時效果大、X 高時趨緩）、倒 U 型（過猶不及）。

★ SmartPLS 官方文件把它描述為 **「is like a self-moderation」**——二次效果就是
「X 調節 X 自己」。本工具的實作正是這樣：交互項的兩個因子都是同一個構念。

## 2. 什麼時候該用、什麼時候不該用

**該用**：理論上有非線性主張（報酬遞減、飽和、倒 U）。

**不該用**

- **資料探勘式地加二次項看會不會顯著**。二次項與主效果的模型比較不是假設檢定的正當用途。
- **X 的分布極偏或有極端值時**。平方會放大極端值的影響。工具不檢核。
- **想用 product indicator 法做**：本工具**硬擋**（實測：「只支援兩個相異構念
  （二次效果與三向以上請用 two-stage）」）。

**常見誤用（三條）**

1. **只看二次項係數的正負判斷曲線形狀。** 曲線的實際走向要看**條件斜率**（§3.3）——
   在資料的實際範圍內，一個「顯著的正二次項」也可能整段都是負斜率。
   實測本工具示範資料：$b_q=+0.0514$（正），但三個水準的斜率是 −0.226／−0.123／−0.021，
   **全段皆負**，只是負得越來越少。
2. **忘記主效果。** 二次項要能解釋，線性項必須在模型裡。本工具**自動補**（實測：`autoAddedPaths = [{F1→Y}]`）。
3. **外推到資料範圍之外**。二次曲線在資料外的行為完全是外插。

## 3. 公式與定義

### 3.1 與 two-stage 調節共用同一條路徑

二次效果在本工具的模型語法中就是「兩個因子都是同一個構念」的交互項：
`{ name: 'F1sq', factors: ['F1','F1'], method: 'two-stage' }`。

引擎的 two-stage 分支對 `factors` 陣列**連乘**、不區分因子是否相同（`pls.js:1650–1654`），
所以二次效果與一般調節走**同一條程式路徑**：

$$z_{I}=\prod_{f\in\text{factors}}y_f = y_{F1}\cdot y_{F1}=y_{F1}^2$$

★ 這也是本組溯源的關鍵：`pls_mod_twostage` 對 seminr 的逐值抽驗，**同時是本組的機制證據**。

### 3.2 第一階段必須排除二次項

SmartPLS 官方文件明載：第一階段取的是**主效果模型（不含二次項）**的構念分數。

本工具的實作滿足這一點：two-stage 分支先以 `curPaths`（僅主效果）呼叫 `estimateStage`
（`pls.js:1639`），交互路徑 `intPaths` 在該次估計**之後**才併入（`pls.js:1665`）。

★ 這是 Session Q3 溯源審計的實作層查核項，本次階段 A 覆核仍成立。

### 3.3 條件斜率（curve）

設線性項係數為 $b_1$、二次項係數為 $b_q$（未標準化量尺，§3.4），則

$$\frac{\mathrm{d}\hat Y}{\mathrm{d}X}=b_1+2\,b_q\,x$$

本工具在 $x\in\{-1,0,+1\}$（即 $\mp1$ SD）三個水準回報條件斜率。

→ `src/lib/stats/pls.js:1985–1992`（二次分支；`quadratic = true` 於 `1958`、斜率於 `1961`）

★ **注意係數 2**：這是微分帶來的，與一般調節的 $\text{slope}=b_1+b_{int}\cdot w$ 不同。
程式碼以 `mult = tg.quadratic ? 2 * sl.level : sl.level` 區分（bootstrap 端亦同）。

### 3.4 係數量尺

與 two-stage 調節相同：引擎回傳標準化係數，回報前除以 $\operatorname{sd}(y^2)$ 還原為未標準化。

→ `pls.js:1951–1972`

★ 實測：`coefStd = 0.06178`、`sd(y²) = 1.20141` → 回報 `coef = 0.05143`。

★ 溯源上的一個代數論證（Session Q3 記錄）：基準端「對標準化平方項做 OLS 再除以 sd」
與「直接對未標準化平方項迴歸」恆等（置中後截距吸收均值），
故回報值即權威文獻要求的未標準化係數。

## 4. 假設前提與本工具的檢核方式

| 前提 | 本工具怎麼檢核 | 違反時的行為 | 位置 |
|---|---|---|---|
| 必須用 two-stage | 驗證器擋下 product indicator／orthogonal 的同構念交互 | **硬擋**（實測確認） | `pls.js:367` |
| 線性主效果在模型中 | 不存在就**自動補** | 記入 `meta.autoAddedPaths`（實測 `[{F1→Y}]`） | `pls.js:1360–1374` |
| 平方項有變異 | $\operatorname{sd}(y^2)>0$ | **硬擋** `interaction-degenerate` | `pls.js:1656–1658` |
| 不與 PLSc 併用 | 建模階段 | **硬擋** | `pls.js:1354–1359` |
| **X 的分布不極端** | ✗ **不檢核** | 無警告——平方會放大極端值 | — |
| **條件斜率的解讀範圍** | ✗ **不限制** | 三個水準固定為 $\mp1$ SD，不隨資料實際範圍調整 | `pls.js:1991` |
| 第二階段不報 fit | `skipFit` | fit 與 GoF 皆 `null` | `pls.js:1909` |

1. **沒有任何第三方數值對照二次效果本身。** seminr 無 quadratic 支援、SmartPLS 4 授權過期。

2. **authority 是線上文件，會改版。** 目前的核對是 2026-07-25 的版本，文件若更新，口徑可能不同——
   工具沒有任何機制偵測這件事。
3. **條件斜率固定在 $\mp1$ SD**，不隨資料的實際範圍調整。極端情形下 $\pm1$ SD 可能落在

4. **曲線的轉折點（$-b_1/2b_q$）沒有回報**，而那通常是二次效果最有實質意義的量。
   使用者要自己算，且工具不提示轉折點是否落在資料範圍內。
5. **極端值敏感性未量化、未警告**。

### R1（通過）獨立重寫與係數 2 的核對

依第 3 節文字規格以 numpy 重寫，7 欄比對**最大絕對差 9.7e−17**。
重點在條件斜率的**係數 2**：$b_1+2b_qx$ 與一般調節的 $b_1+b_{int}w$ 不同，
寫錯的話三個斜率會全錯，而基準值會立刻抓到——本次三個斜率全部對到 1e−16 量級。

### R18（L1，已記錄）二次項的正負不等於曲線的走向

實測示範資料：$b_q=+0.0514$（正的二次項），但三個水準的條件斜率為
**−0.2263／−0.1234／−0.0206**——全段皆負，只是負得越來越少。

若使用者只看「二次項為正」就描述成「X 越高、效果越強」，那是錯的。
本工具**已經同時回報條件斜率**，所以資訊是齊的；但 UI 沒有明說「請以條件斜率判讀曲線走向」。

建議併入未來的 Notes 修訂，不在階段 A 的修正範圍。分級 **L1**。
