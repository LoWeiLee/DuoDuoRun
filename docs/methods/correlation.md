## 1. 這個方法在回答什麼問題

**「兩個變項是不是一起變動？一起變動的程度有多強、方向是哪一邊？」**

兩種答法：

| 方法 | 衡量的是 | 對什麼敏感 |
|---|---|---|
| **Pearson $r$** | 兩者的**線性**共變程度 | 線性關係；受離群值與非線性影響大 |
| **Spearman $\rho$** | 兩者**名次**的線性共變程度 | 任何單調關係；對離群值穩健 |

★ **相關不等於因果**，而且**相關為 0 不等於無關**——完美的 U 形關係，Pearson $r$ 可以是 0。

## 2. 什麼時候該用、什麼時候不該用

**該用**

- 探索兩個連續變項的關聯
- 迴歸分析前的共線性初探
- 量表題目間的關聯檢視

**不該用**

- ★ **一次看很多對，然後只報顯著的那幾對。** $10$ 個變項有 $45$ 對，$\alpha=.05$ 下期望約 2 對假陽性。
  ★ **本工具不做任何多重比較校正，也不提醒**（E88）
- **非線性關係只報 Pearson**
- **兩組資料來自不同群體時混在一起算**（Simpson's paradox）

**常見誤用**

1. ★ **拿 $r$ 的大小直接說「強／中／弱」而不看 $n$。** 本工具教學模式有這個判讀（$|r|<.3$ 弱、$<.5$ 中、$\ge.5$ 強，
   `Result.jsx:138–143`），★ **但這個門檻沒有引用出處**（E89）
2. ★ **把 Spearman 當成「小樣本專用」。** 本工具的 Spearman $p$ 走 $t$ 近似，**小樣本反而是它最不準的地方**（見 §3.3 與 §6）
3. **報了 $r$ 沒報 $n$**（本工具矩陣每格都印 $n$，不會有這個問題）
4. ★ **報了 $r$ 卻沒報信賴區間。** APA 7 要求效果量附 CI，而**本工具完全沒有提供**（見 §6）

## 3. 公式與定義

### 3.1 符號

| 符號 | 意思 |
|---|---|
| $n$ | 該配對的有效樣本數（pairwise 剔除後） |
| $\bar x$、$\bar y$ | 兩變項的平均 |
| $R(x_i)$ | $x_i$ 在 $x$ 中的名次（並列取平均名次） |

### 3.2 Pearson $r$ 與其檢定（`correlation.js:25–52`）

$$r=\frac{\sum(x_i-\bar x)(y_i-\bar y)}{\sqrt{\sum(x_i-\bar x)^2\sum(y_i-\bar y)^2}},\qquad
t=\frac{r\sqrt{n-2}}{\sqrt{1-r^2}},\qquad \mathrm{df}=n-2$$

$p$ 為雙尾 $t$（`correlation.js:49–50`）。
★ 邊界：$|r|\ge1$ 時 $t$ 發散，直接回 $t=\pm\infty$、$p=0$（`correlation.js:48`）；
任一側零變異回 `NaN` 並附旗標（`correlation.js:43`，見 §3.4）。

### 3.3 ★ Spearman $\rho$：名次化後套 Pearson，$p$ 走 $t$ 近似（`correlation.js:66–84`）

$$\rho=r\bigl(R(x),R(y)\bigr)$$

並列取**平均名次**（`ranks.js`），因此本式適用有並列的資料。
$p$ **沿用 §3.2 的 $t$ 公式**（$\mathrm{df}=n-2$）——這與 scipy 的 `spearmanr` 相同。

★★ **這是本頁最重要的慣例分歧**：

| 軟體 | 無並列時的 $p$ | 有並列時 |
|---|---|---|
| ★ **本工具**、scipy | **一律 $t$ 近似** | 同左 |
| **R `cor.test`** | **精確法**（$n\le9$ 全枚舉、$10\le n<1290$ 走 AS 89 Edgeworth） | 退回近似並發警告 |
| SPSS | $t$ 近似 | 同左 |

**差多少**（2026-07-30 實測，見 §6）：本工具的 $p$ **系統性偏小（偏寬鬆）**，
$n=6$ 時最糟可小 **3.5 倍**，$n\ge20$ 後偏低 $\le12\%$，$n\ge40$ 內 4%。
★ **但 216 組掃描中 .05 判定翻面 0 組。**

### 3.4 零變異與矩陣的邊界（`correlation.js:43`、`125–153`）

任一側為常數 ⇒ 分母為 0 ⇒ 回 `{ r: NaN, ..., zeroVariance: true, xConstant, yConstant }`。
★ **`xConstant`／`yConstant` 是 2026-07-30 新增的**：舊版只有一個 `zeroVariance` 旗標，
而它對**整組配對**都成立，UI 分不出是哪一欄才是常數欄（見 §8 的 R67）。

矩陣採 **pairwise 剔除**（`correlation.js:139–150`）：每一格只要求該兩欄都有值，
所以**不同格的 $n$ 可以不同**——報表每格都印 $n$ 就是為了這件事。

## 4. 假設前提與本工具的檢核方式

| 前提 | 本工具怎麼處理 |
|---|---|
| 線性（Pearson） | ★ **不檢核、不提醒**——沒有散布圖，使用者無從判斷（E90） |
| 雙變量常態（Pearson 的 $t$ 檢定） | `assumptionChecker.js:210+` 的 `checkCorrelation` 對每個變項跑 Shapiro-Wilk |
| 至少順序尺度（Spearman） | Config 只列 `continuous` 與 `ordinal` |
| 無極端離群值 | **不檢核** |
| $n\ge3$ | 硬擋（`correlation.js:27`、`69`） |
| 零變異 | ★ **2026-07-30 起在矩陣下方顯性說明是哪幾欄**（R67） |
| 遺漏值 | **pairwise**，每格 $n$ 獨立顯示 |

### R64（L1）Spearman 的 $t$ 近似與 R 的精確法：已量化，不改實作

**發現**　本工具（與 scipy 相同）一律走 $t$ 近似；R 的 `cor.test` 預設在
$n<1290$ 且無並列時走精確法。07 號抽驗在 $n=60$ 那一點量到：
R 精確 $p=1.705\times10^{-5}$ vs 本工具 $1.252\times10^{-5}$ ⇒ **本工具小 1.36 倍**。

★ **A5b 的 R58 教訓是「一個點量不出通則」**，故以 216 組確定性排列掃描（見 §6 第 4~6 道）：
比值 **0.288 ~ 1.005**，方向系統性偏寬鬆但隨 $n$ 迅速收斂，★★ **.05 判定翻面 0 組**。

**Kevin 2026-07-30 裁決：書面化即可，不改實作、不加 UI 警告。**
理由：R58 是**量到 1.1% 偽顯著才加警告**，本批是 **0%**；且小 $n$ 時精確 $p$ 呈粗糙階梯
（$n=6$ 的最小雙尾 $p$ 就是 0.0167），比值雖大但兩者落在 .05 同側。

★ **同日裁決的第二件事**：有並列的區域**誠實標註未量化、列 backlog**，
理由是 R 在那一格會退回近似 ⇒ **不存在現成的權威**（見 §6 尚未驗證第 1 項）。

### R67（L2）相關矩陣的零變異欄只印「—」而不說明

**發現**（實跑）：`pearsonCorr` 早就回傳 `zeroVariance: true`，
但 `grep` 確認**沒有任何 UI 元件讀它**（孤兒欄位，同 A3a 的四項）。後果：
- 矩陣該格印 `fmtNum(NaN)` ＝「—」、`p = —`，但 $n$ 照印
- 教學模式的解讀區被 `Number.isFinite(cell.r)` **靜默略過**該配對

⇒ 使用者看得到空格，**看不到原因**，也不知道那一欄是常數欄。

★ **修復時發現舊旗標本身不夠用**：`zeroVariance` 對**整組配對**都成立，
矩陣裡 $(a,b)$ 被標記時 $a$ 與 $b$ 都可能是那個常數欄——**只有兩欄時完全分不出來**。
