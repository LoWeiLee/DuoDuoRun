# t 檢定（單一樣本／獨立樣本／成對樣本）

> 最後更新：2026-07-29（階段 A / A5a）

## 1. 這個方法在回答什麼問題

t 檢定回答同一個形狀的問題：**兩個平均數之間的差距，大到不像是抽樣誤差造成的嗎？**
差別只在「哪兩個平均數」：

| 型別 | 比的是 | 典型問題 |
|---|---|---|
| 單一樣本 | 樣本平均 vs **一個已知的比較值** $\mu_0$ | 本校學生的滿意度是否高於全國常模 4.0？ |
| 獨立樣本 | **兩群不同的人** | 男性與女性的工作投入有沒有差異？ |
| 成對樣本 | **同一群人的兩次測量**（或配對的兩人） | 訓練前後有沒有進步？ |

三者的邏輯相同：把「觀察到的差距」除以「這個差距的標準誤」，得到一個以標準誤為單位的距離 $t$，
再問「在虛無假設（沒有差異）之下，跑出這麼遠的機率是多少」。

★ **成對與獨立不能互換。** 同一群人的前後測若當成兩群獨立樣本跑，
會把「個體之間本來就有的差異」算進誤差裡，**檢定力大幅下降**。這是最常見的誤用。

## 2. 什麼時候該用、什麼時候不該用

**該用**

- 依變項連續、自變項是二分類別（或與固定值比較）
- 樣本量中等以上，或雖小但分布大致對稱

**不該用**

- ★ **要比三組以上**：不能兩兩跑 t 檢定。跑三次 α = .05 的檢定，至少一次誤判的機率約 14%。用單因子 ANOVA（`anova-oneway.md`）
- **依變項是次序或嚴重偏態的小樣本**：改用 Mann-Whitney（獨立）或 Wilcoxon 符號等級（成對）
- **資料有巢狀或群集結構**（同班學生、同公司員工）：獨立性假設不成立
- ★ **某一組完全沒有變異**：$t$ 在數學上發散。2026-07-29 起工具會警告並停止下判定（見 R51）

**常見誤用**

1. ★ **拿 $p$ 值大小當效果大小。** $p$ 受樣本量支配；$n=1000$ 時毫無實務意義的差距也會顯著。要看 Cohen's $d$
2. ★ **把 Welch 當成「變異數同質時不能用」。** 恰恰相反——Welch 在同質時幾乎不損失檢定力，不同質時才救得回來，所以本工具**一律用 Welch**（§3.2）
3. **前提檢核不顯著就宣稱「符合常態」。** 不拒絕不等於成立，小樣本的 Shapiro-Wilk 檢定力很低
4. **成對 t 用錯配對方向**：$d$ 的正負會反過來，敘述句跟著反

## 3. 公式與定義

### 3.1 三種型別的統計量

| 型別 | $t$ | $\mathrm{df}$ | 程式碼 |
|---|---|---|---|
| 單一樣本 | $\dfrac{\bar x-\mu_0}{s/\sqrt n}$ | $n-1$ | `ttest.js:166–207` |
| 成對 | 對差值 $d_i=x_{1i}-x_{2i}$ 做單一樣本 $t$（$\mu_0=0$） | $n-1$ | `ttest.js:115–164` |
| 獨立（Welch） | $\dfrac{\bar x_1-\bar x_2}{\sqrt{s_1^2/n_1+s_2^2/n_2}}$ | 見 §3.2 | `ttest.js:49–108` |

$p$ 一律為**雙尾**：$p=2\cdot P(T_{\mathrm{df}}>|t|)$。

### 3.2 ★ 慣例：獨立樣本一律走 Welch

$$\mathrm{df}_{\text{Welch}}=\frac{\left(\dfrac{s_1^2}{n_1}+\dfrac{s_2^2}{n_2}\right)^{2}}{\dfrac{(s_1^2/n_1)^2}{n_1-1}+\dfrac{(s_2^2/n_2)^2}{n_2-1}}$$

（`ttest.js:77–82`）。**本工具不提供 Student 的等變異版本**，也沒有「先看 Levene 再決定用哪個」的分支。

★ 這與 SPSS 的預設呈現不同：SPSS 的 t 檢定表**同時列出**等變異與不等變異兩列，
使用者依 Levene 的結果自己挑一列。⇒ **拿本工具的 df 與 SPSS 對照時，要對到 SPSS 的第二列**
（"Equal variances not assumed"）。這是最容易讓使用者以為「數字不一樣」的一項慣例差異。

★ 補充：`levene` 的結果仍然會在前提檢核區顯示（§4），但**不改變估計法**——它是給讀者判讀用的資訊，不是分支條件。

### 3.3 Cohen's $d$ 的三種分母

| 型別 | 分母 | 程式碼 |
|---|---|---|
| 獨立 | **pooled SD**：$\sqrt{\dfrac{(n_1-1)s_1^2+(n_2-1)s_2^2}{n_1+n_2-2}}$ | `ttest.js:84–91` |
| 成對 | **差值的 SD** $s_d$（standardized mean change） | `ttest.js:135–140` |
| 單一樣本 | 樣本 SD $s$ | `ttest.js:186–190` |

★ **成對的 $d$ 用 $s_d$ 而不是原始分數的 SD，是一項有爭議的慣例分歧。**
另一種常見寫法是 Cohen's $d_{av}$（用兩次測量 SD 的平均）。兩者可以差很多——
相關越高，$s_d$ 越小，$d$ 就越大。本工具採 $s_d$（與 SPSS 的「成對樣本效果量」一致），
**但報表未標示採的是哪一種**（見第 6 節）。

判讀門檻（`ttest.js:35–43`）：$|d|<0.2$ 微小、$<0.5$ 小、$<0.8$ 中、$\ge0.8$ 大（Cohen 1988 慣例）。

### 3.4 ★ 零變異的處理

$s=0$ 或 pooled SD $=0$ 時 $t$ 與 $d$ 在數學上發散。引擎的處理（`ttest.js:67–92`、`156`、`206`）：

- 獨立樣本：$\mathrm{se}=0$ 時若兩平均相同取 $t=0,p=1$；否則 $t=\pm\infty$
- pooled SD $=0$ 時 $d=0$（平均相同）或 $\pm\infty$
- 三種型別都回傳 `zeroVarianceWarning`

★ **修復前這個旗標是孤兒**（R51）：實測報表印出 **`t = —`、`p < .001` 且亮綠燈、`d = —`**——
失敗偽裝成一個高度顯著卻沒有數字的結果。2026-07-29 起補上警告框、抽掉燈號、APA 句加警語。

## 4. 假設前提與本工具的檢核方式

★ t 檢定是 `assumptionChecker.js:283` 明文支援的兩支之一（另一支是單因子 ANOVA）。

| 前提 | 工具怎麼檢核 | 違反時 |
|---|---|---|
| 常態 | ✅ **Shapiro-Wilk**，逐組／逐變項（`ttest/Result.jsx:67–74`） | 紅燈＋警告框，不擋 |
| 變異數同質 | ✅ **Levene**（`ttest/Result.jsx:56–64`） | 紅燈；★ **但不改變估計法**——本工具一律 Welch（§3.2） |
| 無缺失值 | ✅ listwise | — |
| ★ 非零變異 | ✅ `zeroVarianceWarning`（2026-07-29 起才有 UI，R51） | 警告框＋不下顯著性判定 |

**沒有檢核、但方法確實要求的**：

1. ★ **獨立性**。同班／同單位的巢狀結構完全不檢核，也無從檢核（需要群集變數）
2. **成對資料的配對正確性**：兩欄是否真的來自同一個人，工具無從得知
3. **離群值**：不篩檢、不警告
4. **測量尺度**：次序變數照跑，不提醒改用無母數

### R51（L2）`zeroVarianceWarning` 是孤兒旗標，零變異時失敗偽裝成成功

**發現**　三種 t 檢定都算了 `zeroVarianceWarning`，**零 UI 消費者**。
實測成對 t（差值全部相同）：引擎回 $t=-\infty$、$p=0$、$d=-\infty$，
而 `fmtNum(±Infinity)` 印「—」、`fmtP(0)` 印「< .001」、`toneForP(0)` 給**綠燈**
⇒ 報表顯示 **`t = —`、`p < .001`（綠）、`d = —`**。
使用者看到的是「一個高度顯著、但沒有數字」的結果，而且 APA 句照樣寫「達顯著差異」。
可達性：常數欄、天花板／地板效應、前後測固定位移都會踩到。

★ 這與 A4 的 R40-i／R40-h 是**同一型**（習慣 5：失敗會不會偽裝成成功），
且共用同一個成因——`fmtNum` 對 ±∞ 回「—」、`fmtP(0)` 回「< .001」。

**處置（Kevin 2026-07-29 核定）**　純呈現層：
`Result.jsx:341–349` 加警告框（指出 $t$ 發散、$p$ 恆為 0、三個數字都不可解讀）；
統計卡的顯著性燈號在該情形下取消（`Result.jsx:358`）；
